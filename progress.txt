## Issue #206 — Atomic per-file import: FitImportService writes in one Room transaction
Completed: 2026-09-19

### What was done

- `FitImportService` now injects `VelometricsDatabase` and wraps `insertSession` through `updateTag`
  (best efforts, intervals + matching, sprint update, tag) in one `withTransaction`; parse/hash/filter/
  metrics stay outside. A kill mid-import leaves nothing or a full row -- never a partial one that dedup
  would treat as imported. Public signature and callers unchanged.
- New `FitImportServiceTransactionTest` (Robolectric + real Room, FIT built with the Garmin encoder):
  successful import commits session + best efforts + tag; a forced `updateTag` failure leaves zero rows
  (`existsByFileName` false) and a retry then imports cleanly.

`testDebugUnitTest` passes.

## Issue #201 — Ride Reveal: RevealCandidateSource seam and a single-file priority rule
Completed: 2026-09-19

### What was done

- New `RevealCandidateSource` interface (`candidates(session)`); `RideMilestoneEvaluator` and
  `PowerCurveAchievementEvaluator` implement it, and `RevealSourceModule` binds all sources `@IntoSet`.
  `RideRevealEvaluator` now takes `Set<RevealCandidateSource>` -- a new source is one class + one binding.
- New `IntervalAchievementRevealSource` turns the persisted #185 interval achievement snapshot into a
  candidate (family `INTERVAL_ACHIEVEMENT`), so a repeated-interval PR can be the hero headline.
- `RideRevealResolver` now owns the whole winner rule: explicit `SCOPE_ORDER` / `FAMILY_ORDER` lists
  (milestone > interval > power curve), and the "Nice ride!" fallback. `RideRevealPriority` lost its
  `Comparable`, the `FALLBACK` sentinel and `FALLBACK` family are gone; `resolve` returns the headline.
- Tests: resolver order/enum-independence, interval-wins-hero end-to-end; `FakeIntervalRepository` is
  now stateful and `fakes/TestSessions.kt` shares a session builder.

`testDebugUnitTest` and `assembleDebug` pass.

## Issue #197 — Unify JSON serialization, duration formatting, and the thousands separator
Completed: 2026-09-19

### What was done

- New `util/Json` is the single owner of the app's only `Gson` instance (plus `toJson`/`parseOrDefault`);
  it replaces `JsonSafeParser` and the seven other `Gson()` forks (main + tests).
- `FormatUtils` is the one home for duration/thousands formatting: added `formatDurationMinSec`
  (moved from `MapOverlayUtils`) and `formatDecimal`; `formatDistanceRounded`,
  `formatElevationGainRounded`, `formatElevationGainPer100km` now use the period separator via
  `formatWithThousandsSeparator` (now negative-safe), so Home and All-time Stats agree ("1.234 km").
- `HomeAddressScreen`, `SettingsScreen`, `ScatterPlotChart` (`xTickFormat` -> `xTickDecimals`) and the
  InfoScreen kcal axis use `FormatUtils` instead of inline `"%.Nf".format`.
- `MapOverlayUtils` keeps only colour interpolation; `groupIntervals`, `avgDurationNormalizedSec`,
  `avgPower`, `isFlowSegment` moved to `domain/service/OverlayAggregation` (tests moved too).

`testDebugUnitTest` passes.
