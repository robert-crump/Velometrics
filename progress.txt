## Issue #204 -- Heart rate vs. distance chart on Session Detail
Completed: 2026-09-19

### What was done

- New nullable `cycling_sessions.hrDistanceSeries` JSON column (Room v21, MIGRATION_20_21): 100 `HrDistancePoint`
  (distanceKm, heartRate, altitudeM) per ride, built at import by `HrDistanceSeriesBuilder` (called from
  `SessionMetricsCalculator`). Point k = first record whose cumulative haversine distance reaches k/100 of the ride;
  point 100 = last record. `computeDistance` now shares the builder's cumulative-distance helper, so the chart's
  X axis ends at `distanceKm`.
- Missing HR (or 0) / altitude at a sampled record falls back to the nearest record within +-5 (earlier wins ties),
  else null. Series is null under 1 km (indoor/no GPS) or with no HR at all. No backfill for pre-existing rides.
- `HrDistanceChart` (Canvas): HR line (null breaks it) over a filled elevation backdrop with faint HR zone bands from
  the *current* max HR setting (`SessionDetailViewModel.maxHr`), drag cursor with distance + bpm readout (no altitude).
  Sits at the top of the Heart Rate section, gated on the series existing.
- Tests: `HrDistanceSeriesBuilderTest` (sampling, fallback window/ties, zero HR, thresholds), migration 20->21.

`testDebugUnitTest` and `assembleDebug` pass. No visual check on a device this run.

## Issue #214 -- Session Narrative assembler + all-time Tag recap + Zone 2 content (supersedes #202)
Completed: 2026-09-19

### What was done

- New `SessionNarrativeAssembler` (domain/service): `build(session)` is the single path for tag-scoped comparison +
  interval fetch (once) + narrative generation; `observe(sessionId)` re-assembles when the session row's tag changes
  (backfill by `reclassifyAll`). Returns null for untagged rides and on repository errors. `SessionDetailViewModel`
  exposes `narrative: StateFlow<SessionNarrative?>` (headline + text), replacing `tagNarrative`.
- `SessionComparator`: `computeComparison(session)` no longer takes a tag; new `computeTagComparison(session, tag)` returns an

  from DAO/repository/fake (untagged Last5/AllPrevious drawer comparison is unchanged).
- `TagComparisonNarrative` now takes a `TagComparison`; Zone 2 renders the fixed 5-metric sentence (each metric drops out
  independently; first rendered one carries "in a typical Zone 2 ride"). Intervals/Recovery keep the single-sentence model,
  now on all-time medians (follow-on issues).
- UI: removed `RideTagLabel` chip/expand state; `RideSummaryGrid` shows always-visible "Vs. other [TAG] rides" + text, nothing
  when untagged.
- Tests: new `SessionNarrativeAssemblerTest`, Zone 2 cases in `TagComparisonNarrativeTest`, tag pool tests in
  `SessionComparatorTest`, recap assertions in `SessionDetailViewModelTest`.
